# AKSHAY — Portfolio

A polished single-page portfolio starter built with plain HTML, CSS and JavaScript.

## Run it

1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with Live Server.
4. Edit the content in `index.html`, styling in `style.css`, and interactions in `script.js`.

## Included

- Intro loader
- Responsive navigation
- Editorial hero section
- Scroll reveal animations
- Parallax background orbs
- Magnetic hover interactions
- Custom desktop cursor
- Work gallery
- Project detail modal
- Responsive mobile layout
- Services section
- About section
- Contact CTA
- Supplied King Leos screenshots used as a portfolio concept image

## Portfolio positioning

The site is intentionally designed as a visual representation of your capabilities, not just a CV. Keep the work section strong and add projects gradually.

Fictional projects should be clearly identified as concepts/demos. The King Leos entry is presented as a redesign concept.


## Live demo links

Each project now has a `demoUrl` in `script.js`.

Example:
`demoUrl:'https://your-deployed-demo.com'`

Replace the `#` placeholder with the real deployed URL. The **Live Demo ↗** button in both the project card and case-study modal will open it in a new tab.

Project cards use browser-style mockups so screenshots look like actual websites rather than flat images.
